Rate-limit headroom

Per-route-group window usage from the X-Ratelimit headers the ESI limiter observes on every response. This is the number the sync loop checks before expanding the hub set — the staged-rollout gate for the remaining families. The limiter backs off automatically: per-group pauses near the floor, global pause on the error budget, and Retry-After honored on 429s.
