Invention plan

The invented blueprint is a parallel branch — it gates only the final build, so the attempts install in wave 1. No job-lock: each attempt consumes its own relic, so all five run in one 1 h window. Expected value 1.3 successes at 5 attempts. blitzrage is out-of-corp: the relics and datacores are contracted to blitzrage before wave 1 installs — the distribution step is a plan item with its own procurement lead.

wireframe Two T3 contrasts with the Panther's invention plan. No decryptor row: the grade choice is price-only — Intact dominates every deterministic axis (Wrecked needs 12.5× the relics per ship), so the plan picks the highest grade the market stocks and moves on. And the fuel decision is attempts-to-buy, not successes-needed: one success yields a 20-run BPC against a ×1 target, so 5 attempts buys 78% confidence and the surplus 19 runs are inventory — blueprint fuel for the next 19 Jackdaws, or a spare BPC to sell. A zero-success batch (22% odds) appends another 1 h window with 5 more relics: the cheapest retry in any chain so far.

Blueprint copy plan

Nothing to copy — no copy plan exists for this chain.

Every blueprint is held as an original (formulas, fuel blocks), a 1000-run site-drop copy (components — run counts exceed job needs by two orders of magnitude), or arrives by invention (the Jackdaw BPC). Copying never enters this chain.

wireframe The absent state — an edge case the M9 surface must handle: a chain with no copying renders this section as absent, not as an error or an empty queue with zero rows. "Nothing to copy" with the one-line reason is the honest rendering; every previous chain had a copy plan, so this state had never drawn until now.
