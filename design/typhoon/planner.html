Plan participants

Who the plan may assign work to — set before Calculate, because eligibility depends on it: skill gates, wave allocation, and the stock meters all resolve against this pool. The corporation follows the main character (set on the Roster) and scopes the shared material pool plus the member set; corp members default to all included and take materials from the office hangars directly, while characters in other corporations need a distribution step (contract / station trade) before their jobs can install. The build plan's pool picker re-runs the calculation against a different pool (what-if); this section sets the pool it starts from.

Corporation: blitz and blitz holdings — from the main character schlepzrage (Director); it scopes the shared material pool (hangars, blueprints, assets) and defines the member set. To target a different corporation, change the main character on the Roster.

Plan facilities

Where each activity runs. Defaults come from the Structures registry (one per activity); overrides are plan-scoped — the registry stays untouched. Every calculation multiplies against these: material requirements (ME rig), job durations (TE rig + structure hull), and install cost (system cost index × facility tax).

This plan multiplies: materials × ME T1 rig (−2.0% at the Azbel, lowsec) · job time × hull −30% and TE T1 rig · install cost = base × system index 3.1% — syncs at M15 × tax 0.5%

wireframe Each dropdown lists every structure registered for that activity (the Structures registry); the registry default arrives pre-selected and an override never writes back. Copying is its own selector (2026-11-22 direction) defaulting to the invention facility's default — copy jobs may run in a separate location with the BPCs transported to the build site, so copying and invention can diverge per plan. The build plan can still override per job (the header pickers re-run; a job's facility line is the per-job record). Rig and hull values are illustrative until confirmed from CCP structure docs (the M3 scope note); the system cost index is M15's sync. Supercapital chains (Hel, Ragnarok) flag the final hull job when the selected manufacturing facility lacks the supercapital assembly capability.
