# Hel mockup set

The supercapital set — same pages, layout, and components as the
reference standard ([`../typhoon/`](../typhoon/README.md), see
[`../README.md`](../README.md) for the binding convention), populated
with the Hel ×1 chain. It exercises what no previous set could: the
**first months-long plan** (≈7.3 months illustrative — the wave bar
compresses to stay readable), the **reaction-slot bottleneck** as the
throughput story (10,478 runs / 31,434 slot-hours dwarf the 47-day
hull), the **underleveled-holder skill gate** (Octavia holds Capital
Ship Construction at 1 against the hull's 4 — a new gate state,
distinct from no-holder, whose remediation is training), the **third
distinct absent-copy cause** (the target's BPC is itself a copy), the
mineral-mountain acquisition meters (Pyerite at 0.4% coverage), and
the early-BPC-acquisition carrying-cost observation on the active
page.

## Data provenance

- Quantities, phases, runs, and the throughput arithmetic come from
  `reference/chains/HEL-CHAIN.md` (the model runs at ×1 against the
  live SDE mirror). Component bills, reaction counts (10,478),
  durations (47.2 d skilled hull, 3 h reactions), and the 79/79
  type counts are SDE data; the Hel BPC's contract acquisition and
  the supercapital assembly facility class are recorded pins.
- Blueprint ownership from the live `blueprints` table, pulled
  2026-11-21: 79 types — 44 owned (the prior chains' world carrying
  over wholesale, plus three neurolink formulas and the Isotropic
  Neofullerene set as live prior-line evidence) and 35 missing.
  Stock figures are real: Pyerite 652,411 against 146.8M (0.4%),
  Tritanium covered 2.2×, all 17 gases at zero, the R4s partial.
- **Skills simulated only for Capital Ship Construction 4** — and
  this set renders the gap as an underleveled-holder state (Octavia
  at 1, the sole holder, training in parallel from day 0) rather
  than an assumed-met gate: the remediation story is training, per
  the skill-plan calculator TODO item. Every reaction gate is held
  live at 5.
- Wave decomposition (the 222-day chain end, wave boundaries, the
  train's completion timing), intermediates movements, and
  market-average figures are **invented for the wireframe** —
  illustrative at this scale more than any prior set, since the
  merged-campaign and pipelining decisions (M5/M9) move months
  here; the real waves are the M9 scheduler's output.
